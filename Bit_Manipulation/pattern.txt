Problem: Check if a Number is Odd or Even

Pattern:
Bit Manipulation / Bitmask

Trigger:
The problem asks about a property that can be determined
from a specific bit of a number.

Key observation:
The least significant bit (LSB) determines odd/even:
LSB = 0 → even
LSB = 1 → odd

Use:
num & 1

Mental trigger:
"Odd/Even → Check the last bit"

Time: O(1)
Space: O(1)




Problem: Get the i-th Bit of a Number

Pattern:
Bit Manipulation / Bitmask

Trigger:
Need to inspect, set, clear, or modify a specific bit
at position i.

Key observation:
Create a mask with only the i-th bit set:
1 << i

Then use AND:
num & (1 << i)

If the result is 0 → i-th bit is 0.
Otherwise → i-th bit is 1.

Mental trigger:
"Specific bit → Create mask with 1 << i → use &"

Time: O(1)
Space: O(1)




Problem: Set the i-th Bit

Pattern:
Bit Manipulation / Bitmask

Trigger:
Need to make a specific bit equal to 1.

Key observation:
Create a mask with only the i-th bit set:
1 << i

Then use OR:
num | (1 << i)

OR with 1 always makes that bit 1, while all other bits remain unchanged.

Mental trigger:
"Set bit → Create mask → OR"

Time: O(1)
Space: O(1)


Problem: Clear the i-th Bit

Pattern:
Bit Manipulation / Bitmask

Trigger:
Need to make a specific bit equal to 0.

Key observation:
Create a mask where every bit is 1 except the i-th bit:
~(1 << i)

Then use AND:
num & ~(1 << i)

Mental trigger:
"Clear bit → NOT mask → AND"

Time: O(1)
Space: O(1)

Problem: Clear Last i Bits

Pattern:
Bit Manipulation / Bitmask

Trigger:
Need to make the last i bits equal to 0.

Key observation:
Create:
(~0) << i

This gives:
11111111...000...000
             ↑
          i zeros

Then AND with num.

Mental trigger:
"Clear last i bits → (~0) << i"

Time: O(1)
Space: O(1)




Problem: Clear Bits from i to j

Pattern:
Bit Manipulation / Range Masking

Trigger:
Need to clear a continuous range of bits.

Key observation:
Create two masks:
Left mask  → keeps bits after j
Right mask → keeps bits before i

Combine them using OR, then AND with num.

Mental trigger:
"Clear range → Keep left + keep right → AND"

Time: O(1)
Space: O(1)





Problem: Check if a Number is a Power of 2

Pattern:
Bit Manipulation / Binary Property

Trigger:
Need to determine whether a number has exactly one set bit.

Key observation:
A positive power of 2 has exactly one 1-bit.

For such a number:
num & (num - 1) == 0

Mental trigger:
"Power of 2 → Exactly one set bit → n & (n-1)"

Time: O(1)
Space: O(1)





Problem: Count Set Bits

Pattern:
Bit Manipulation / Bit Counting

Trigger:
Need to count how many 1s are present in the binary representation.

Key observation:
Check each bit and count whenever it is 1.

Mental trigger:
"Count 1s in binary → Count set bits"

Time: O(log n)
Space: O(1)



Problem: Fast Exponentiation / Binary Exponentiation

Pattern:
Binary Exponentiation

Trigger:
Need to calculate a^n efficiently when n can be large.

Key observation:
Represent the exponent n in binary.
For every set bit in n, multiply the current answer by a.

Square the base after every bit and shift n right.

Mental trigger:
"Large exponent → Binary exponentiation → Check bits of n"

Time: O(log n)
Space: O(1)
