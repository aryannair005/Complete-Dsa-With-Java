Problem: Check if a Number is Odd or Even

Pattern:
Bit Manipulation / Bitmask

Trigger:
The problem asks about a property that can be determined
from a specific bit of a number.

Key observation:
The least significant bit (LSB) determines odd/even:
LSB = 0 → even
LSB = 1 → odd

Use:
num & 1

Mental trigger:
"Odd/Even → Check the last bit"

Time: O(1)
Space: O(1)




Problem: Get the i-th Bit of a Number

Pattern:
Bit Manipulation / Bitmask

Trigger:
Need to inspect, set, clear, or modify a specific bit
at position i.

Key observation:
Create a mask with only the i-th bit set:
1 << i

Then use AND:
num & (1 << i)

If the result is 0 → i-th bit is 0.
Otherwise → i-th bit is 1.

Mental trigger:
"Specific bit → Create mask with 1 << i → use &"

Time: O(1)
Space: O(1)




Problem: Set the i-th Bit

Pattern:
Bit Manipulation / Bitmask

Trigger:
Need to make a specific bit equal to 1.

Key observation:
Create a mask with only the i-th bit set:
1 << i

Then use OR:
num | (1 << i)

OR with 1 always makes that bit 1, while all other bits remain unchanged.

Mental trigger:
"Set bit → Create mask → OR"

Time: O(1)
Space: O(1)
